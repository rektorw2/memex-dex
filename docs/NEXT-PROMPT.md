Ты — Web3-инженер, системный трейдер и UX-дизайнер в одном лице. Проект `memex-dex` (Next.js 15 + Tailwind, `@memex/core`, Fastify API, Prisma). Страница `/agent` — автономный PAPER-агент по сигналам OKX на Solana.

## Текущее состояние (сентябрь 2026, uncommitted в рабочей папке)

- Редизайн `/agent`: hero с капиталом (count-up), PAPER/LIVE карточки, анимированный «Путь решения», вкладки со скользящим индикатором, кольцо капитала, кривая с отрисовкой, полоса просадки. Все анимации отключаются при `prefers-reduced-motion` (тест-инвариант в `retired-calls.contract.test.ts`).
- Режимы выхода: `packages/core/src/paper-exit.ts` — `TARGET` / `PROTECTED` / `LADDER` / `TRAILING`; план снимается при входе (`PaperAgentAllocation.exitPlan/exitState`), частичные продажи через `PARTIAL_EXIT`; `POST /admin/paper-agent/panic`. Миграция `20260908100000_add_paper_exit_plan` зарегистрирована в `production-schema-repair.ts`.
- Тесты: core 2029, api 1677, web 415 — все зелёные. Документация: `docs/paper-agent.md`, раздел «Правило выхода».

Перед началом: `npm run db:generate && npm test`. Ничего не коммить — я смотрю diff сам.

## Цель этой сессии: простота

Правило: **на первом экране — только то, что нужно, чтобы за 5 секунд ответить на три вопроса**: (1) агент работает? (2) сколько денег и как идёт? (3) что он сейчас держит? Всё остальное — на второй уровень (вкладка, disclosure, отдельная страница).

### Задачи по порядку

1. **Один статус вместо трёх блоков.** Сейчас состояние размазано: чип «Работает» в hero, карточки PAPER/LIVE, «Путь решения». Свести в одну строку-«светофор» под заголовком: `● Работает · WebSocket · 406 сигналов/24ч · 2 позиции · выход: Лестница`. Карточку LIVE убрать с первого экрана — оставить одну строку «LIVE заблокирован» со ссылкой на вкладку «Подготовка LIVE».
2. **Новая вкладка «Подготовка LIVE».** Перенести туда всё из `Phase4Foundation` (пополнение, подпись, ступени devnet, semi-auto). На вкладке «Обзор» их не должно быть. Тесты, которые ищут эти тексты (`agent-page.test.tsx`), переключить на новую вкладку — тексты и `data-*` атрибуты сохранить.
3. **Обзор = капитал + позиции.** Показать открытые позиции прямо в обзоре (компактные строки: токен, PnL, множитель, стоп, ближайшая цель), вкладку «Позиции» оставить как расширенный вид. Пустое состояние — одна строка «Ждёт подходящий сигнал», не карточка на весь экран.
4. **«Путь решения» → живой лог.** Заменить четыре статичные плитки на ленту последних 5 событий агента (сигнал получен → пропущен/вошёл, причина одним словом), с тем же анимированным появлением. Это отвечает на «что он сейчас делает», плитки — нет.
5. **Настройки — мастер из трёх шагов** вместо трёх панелей: 1) капитал и режим распределения, 2) правило выхода (четыре карточки, уже есть), 3) подтверждение с итогом словами: «$1000, Autopilot Balanced, Лестница: 40% на 1.6×, 30% на 2×, стоп −35%». Кнопки Start/Stop/Panic — в отдельный липкий бар сверху вкладки, а не внутри панели.
6. **Мобильный.** Нижний sticky-бар с балансом и статусом при прокрутке; hero не должен занимать больше 40% высоты экрана телефона.
7. **Тексты.** Убрать слово «контур» с публичных экранов, заменить на обычные слова. Все подписи ≤ 6 слов. Каждый код причины (`exitReason`, `decisionCode`) показывается только словами (`EXIT_REASON_LABELS`, `humanDecision`).

### Ограничения

- Не ломать тесты-контракты: тексты `PAPER`, `Solana`, `PAPER · АКТИВНЫЙ КОНТУР`, `LIVE · ЗАБЛОКИРОВАН`, `Этапы пополнения`, USDC mint, кнопки «Подтверждение LIVE недоступно» / «LIVE kill switch недоступен», `data-live-stage`, `data-rpc-state`, `data-deposit-status`, `data-signing-status` — сохранить (можно переместить на другую вкладку).
- Палитра проекта: 4 цвета (accent/up/down/warn), без неона и постоянного свечения. Новые анимации — только opacity/transform, и каждая обязана попасть в блок `prefers-reduced-motion` (иначе тест упадёт).
- Публичный API `/paper-agent` не менять без нужды; если добавляешь поле — оно необязательное, старый сервер не должен ронять страницу.

### Как сдавать

Для каждой задачи: скриншот до/после (390px и 1280px), `npm test -w @memex/web` зелёный, список изменённых файлов. В конце — таблица «что убрано с первого экрана и куда переехало».

## Решения, уже принятые (8 сентября 2026)

1. Главный пользователь — подписчик Pro, который смотрит. Настройки и Panic уезжают на `/agent/settings` (только ADMIN, `RouteGuard`); на `/agent` админ видит лишь ссылку «Настройки →» в шапке.
2. «Подготовка LIVE» — отдельная вкладка. В обзоре одна строка: «LIVE заблокирован · 2 из 5 ступеней».
3. «Путь решения» → лента: входы/выходы развёрнуто, пропуски свёрнуты одной строкой с разбивкой по причинам.
4. Настройки — мастер из 3 шагов вместо панелей, с итогом словами перед «Применить».

## Вопросы, которые остались

1. Мобильный — приоритет №1 или десктоп важнее? (Влияет на sticky-бар и на то, сколько позиций показывать в обзоре.)
2. Нужен ли подписчику Pro вообще видеть вкладку «Подготовка LIVE», или только строку-статус? Если только строку — вкладка становится админской.
3. Итог дня в шапке («сегодня: +$18 · 3 сделки · 2 в плюс») — делать? Нужно поле `metrics24h.realizedPnlUsd` в API.
4. Лента: сколько событий держать на первом экране — 5 или 10?
