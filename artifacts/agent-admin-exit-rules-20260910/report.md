# Все пять правил PAPER для администратора

10 сентября 2026. Выполнено по уточнению владельца: «сделай для админа все пять». Это разрешённое изменение прежнего ограничения PAPER; правила LIVE остаются прежними.

## Причина и изменение

Форма PAPER использовала `phase4.allowedExitModes`, рассчитанный из `LIVE_AGENT_CONTROL_MODE=semi-auto`. Поэтому четыре карточки скрывались, а выбранный сохранённый `TRAILING_PURE` автоматически заменялся в черновике формы на TARGET. Административный API применял то же ограничение. Просмотр формы и включение агента сохранённый план не меняли.

Read-only проверка production в 01:52:50 UTC подтвердила включённый агент и сохранённый TRAILING_PURE: трейлинг 50% с момента входа, фиксация 50% на 2×. Переключение LIVE в auto не является решением: текущий сервер запрещает такой запуск.

Теперь администратор видит и сохраняет все пять PAPER-правил: TARGET, PROTECTED, LADDER, TRAILING, TRAILING_PURE. Форма сохраняет выбор действующего плана. Административный маршрут проверяет корректность плана и создаёт виртуальный счёт с аудитом; защита requireAdmin и ограничение сервиса EXECUTION_MODE=paper сохранены. Обычный пользователь не получает форму и не может сохранить план прямым запросом.

`phase4.controlMode`, `phase4.allowedExitModes`, core-проверки semi-auto/auto, ограничения запуска, LIVE, подпись и исполнение не изменены. Существующие планы и исторические позиции не пересчитываются. Порог $600 и официальный OKX Signal не затронуты.

## Публикация и ограничения

Новых миграций или production-переменных не требуется. Публиковать сначала API, затем статический web: старый API продолжает отклонять четыре правила, даже если обновить только форму. Прежний план публикации с тремя миграциями для более старых установок остаётся актуальным.

Изменения подготовлены локально; коммит, push и деплой не выполнялись. Production-план выхода и переключатель не изменялись. Предыдущие незакоммиченные регрессии по второй позиции и OKX 402 сохранены.

Это исправление настройки правил не восстанавливает квоту OKX. Для полной PAPER-проверки по-прежнему требуются доступность источника, следующий допустимый production-вход → сопровождение → выход, наблюдение ≥24 часов и восстановление WS.
