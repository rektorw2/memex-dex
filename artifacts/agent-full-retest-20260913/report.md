- Один дополнительный запрос `/api/v6/dex/market/price` для токена первой позиции вернул **HTTP 200, code 0**, положительную цену и время провайдера, близкое ко времени запроса. `price-check.json`. Использованы текущие серверные credentials без вывода значений; сделок и записи котировки в БД диагностикой не было.
- UI подтверждает: WS login успешен, подписка отклонена **60036**, событий WS нет. Источник работает через REST. Обход пяти подтверждённых сетей занимает **300 секунд** при максимальном сроке решения **30 секунд**. REST-бюджет обозначен `BUDGET_UNCONFIRMED`. Успешный REST-ответ сам по себе не доказывает своевременность полученных событий.
- Работа без посетителей подтверждена изолированным E2E, где worker сам обнаруживает сигнал в PostgreSQL, получает внешнюю тестовую цену, открывает, переоценивает и закрывает позицию после очистки горячего кэша. В production посетители принудительно не отключались и новый цикл позиции за этот период не произошёл.

## Итог и следующие production-проверки

Нового воспроизводимого дефекта в проверенных сценариях не найдено. Текущее отсутствие входов объясняется недопустимыми поступившими сигналами; известное ограничение транспорта остаётся: WS недоступен, текущий REST не обеспечивает доставку за 30 секунд. Публикация административного UI и оптимизации расходов сама по себе этот транспортный вопрос не решит.

Для подтверждения готовности нужны:

1. Восстановление подписки и событий официального OKX Signal по WS, включая проверку разрыва и восстановления; либо отдельно обеспеченная квотой своевременная REST-доставка. Квоту, тариф и частоту эта проверка не меняла.
2. Настоящий следующий допустимый production-вход → сопровождение свежими ценами → выход, с фиксацией времени сигнала, даты пула, движения капитала и отсутствия дублей.
3. Непрерывное наблюдение не менее 24 часов с проверкой источника, heartbeat, ошибок и памяти.

Новых миграций нет. Прежний план для более ранних установок сохраняет три миграции: `20260908130000_add_agent_live_wallet`, `20260909100000_add_worker_heartbeat`, `20260909120000_add_paper_metadata_gate`. Для уже подготовленных административных изменений порядок публикации — API, затем web; оптимизация запросов требует отдельной публикации API после коммита и ревью.

В этой проверке добавлены только новый отчёт и доказательства. Порог $600, возраст 15 минут, дедлайн 30 секунд, официальный OKX Signal как единственный источник, правила LIVE и защита от дублей сохранены. Коммит, push, деплой, изменение production-настроек и сделки не выполнялись. Предыдущие изменения и доказательства не перезаписывались.
